### 2.2 Maximum sans `max()`

Sans utiliser la fonction `max()`, écris un programme qui trouve la plus grande valeur dans une liste de nombres.

```python
valeurs = [34, 12, 78, 56, 91, 23, 67]
```

##### Résultat attendu
```
Le maximum est : 91
```

<details>
<summary>💡 Indice</summary>

Commence par supposer que le premier élément est le maximum, puis compare avec chaque élément suivant.

</details>

<details>
<summary>🔑 Voir la solution</summary>

```python "for" "in" {2,4,5}
valeurs = [34, 12, 78, 56, 91, 23, 67]
maximum = valeurs[0]

for valeur in valeurs:
    if valeur > maximum:
        maximum = valeur

print("Le maximum est :", maximum)
```

<Aside type='tip' title='Pourquoi valeurs[0] ?'>
On initialise `maximum` avec le premier élément plutôt qu'avec `0`. Si tous les nombres étaient négatifs, `0` donnerait un faux résultat.

### 2.4 Somme cumulative

Écris un programme qui, à partir d'une liste de nombres, produit une nouvelle liste où chaque élément est la **somme de tous les éléments précédents** (incluant lui-même).


Écris un programme qui demande les notes d'un groupe d'étudiants (saisie terminée par `-1`), puis affiche uniquement les notes de **60 et plus**, triées en ordre croissant.

### 3.4 Fusionner deux listes triées

Écris un programme qui fusionne **deux listes déjà triées** en une seule liste triée, **sans utiliser `sorted()`** ni `.sort()`.

```python
liste_a = [1, 4, 7, 9, 12]
liste_b = [2, 3, 5, 8, 10, 11]
```

##### Résultat attendu
```
Fusionnée : [1, 2, 3, 4, 5, 7, 8, 9, 10, 11, 12]
```

<details>
<summary>💡 Indice</summary>

Utilise deux indices `i` et `j` qui avancent chacun dans leur liste. À chaque étape, ajoute le plus petit des deux éléments pointés.

</details>

<details>
 <summary>🔑 Voir la solution</summary>

```python "while" "append" {6,8,10,14,17}
liste_a = [1, 4, 7, 9, 12]
liste_b = [2, 3, 5, 8, 10, 11]
fusionnee = []

i = 0
j = 0

while i < len(liste_a) and j < len(liste_b):
    if liste_a[i] <= liste_b[j]:
        fusionnee.append(liste_a[i])
        i = i + 1
    else:
        fusionnee.append(liste_b[j])
        j = j + 1

while i < len(liste_a):
    fusionnee.append(liste_a[i])
    i = i + 1

while j < len(liste_b):
    fusionnee.append(liste_b[j])
    j = j + 1

print("Fusionnée :", fusionnee)
```

<Aside type='note' title='Algorithme de fusion'>
C'est l'algorithme de **fusion** (*merge*), un classique en informatique. Il est au cœur du tri fusion (*merge sort*), un des algorithmes de tri les plus efficaces.
</Aside>

</details>

### 4.1 Bulletin de notes

Deux listes parallèles contiennent les noms des étudiants et leurs notes. Écris un programme qui affiche le bulletin complet et identifie l'étudiant avec la **meilleure note**.

```python
noms = ["Alice", "Bob", "Charlie", "Diana", "Eve"]
notes = [88, 72, 95, 81, 90]
```

##### Résultat attendu
```
=== Bulletin ===
Alice    : 88
Bob      : 72
Charlie  : 95
Diana    : 81
Eve      : 90

Meilleure note : Charlie avec 95
```

<details>
<summary>💡 Indice</summary>

Trouve l'indice du maximum dans la liste `notes`, puis utilise cet indice pour retrouver le nom correspondant dans `noms`.

</details>

<details>
  <summary>🔑 Voir la solution</summary>

```python "range" "len" "max" "index" "format"
noms = ["Alice", "Bob", "Charlie", "Diana", "Eve"]
notes = [88, 72, 95, 81, 90]

print("=== Bulletin ===")
for i in range(len(noms)):
    espaces = " " * (9 - len(noms[i]))
    print(noms[i] + espaces + ":", notes[i])

meilleure = max(notes)
position = notes.index(meilleure)
print()
print("Meilleure note :", noms[position], "avec", meilleure)
```

<Aside type='tip' title='Listes parallèles'>
Les listes `noms` et `notes` sont **parallèles** : l'élément à l'indice `i` dans l'une correspond à l'élément à l'indice `i` dans l'autre. C'est un patron très courant avant d'apprendre les dictionnaires.
</Aside>

</details>

## Projet — Wordle

### Le jeu

Wordle est un jeu de devinette de mots.

<Steps>
1. Un mot secret de **5 lettres** est choisi au hasard.
2. Le joueur a **6 tentatives** pour le deviner.
3. À chaque tentative, le programme donne un **indice** pour chaque lettre :
   - La **lettre elle-même** → bonne position
   - Le caractère **❗** → lettre présente mais **mauvaise position**
   - Le caractère **❌** → lettre **absente** du mot
4. Les accents sont ignorés (`ÉTAPE` → `ETAPE`).
</Steps>

#### Exemple de partie

Le mot secret est `MARGE`.

```
========= WORDLE =========

Tentative 1/6
Entre un mot de 5 lettres : gamer
  GAMER → ❗[A]❗❗❗

Tentative 2/6
Entre un mot de 5 lettres : table
  GAMER → ❗[A]❗❗❗
  TABLE → ❌[A]❌❌[E]

Tentative 3/6
Entre un mot de 5 lettres : marge
  GAMER → ❗[A]❗❗❗
  TABLE → ❌[A]❌❌[E]
  MARGE → [M][A][R][G][E]

Bravo ! Trouvé en 3 tentatives !
```

Détail de l'évaluation de `GAMER` :

| Position | 0 | 1 | 2 | 3 | 4 |
|---|---|---|---|---|---|
| Secret | M | A | R | G | E |
| Essai | G | A | M | E | R |
| Résultat | `!` | `A` | `!` | `!` | `!` |

- `G` est dans `MARGE` mais pas à la position 0 → `!`
- `A` est à la bonne position → `A`
- `M` est dans `MARGE` mais pas à la position 2 → `!`
- `E` est dans `MARGE` mais pas à la position 3 → `!`
- `R` est dans `MARGE` mais pas à la position 4 → `!`

```python "def" "return" "for" "range" "while" "break" "append" "in" "format" "random.choice" "upper" "len" "index"
import random
 
MOTS = [
    "MARGE", "TABLE", "LIGNE", "POMME", "ROUTE",
    "BRISE", "CRANE", "DOUTE", "FERME", "GLACE",
    "HERBE", "JUSTE", "LAMPE", "NUAGE", "OLIVE",
    "PERLE", "RONDE", "SABLE", "TIGRE", "VITRE",
    "ABIME", "CARGO", "ETAPE", "FORET", "GUIDE"
]
 
MAX_TENTATIVES = 6
 
 
def retirer_accents(mot):
    avec = ["É", "È", "Ê", "Ë", "À", "Â", "Ù", "Û", "Ô", "Î", "Ï", "Ç"]
    sans = ["E", "E", "E", "E", "A", "A", "U", "U", "O", "I", "I", "C"]
 
    resultat = []
    for caractere in mot:
        if caractere in avec:
            resultat.append(sans[avec.index(caractere)])
        else:
            resultat.append(caractere)
 
    mot_propre = ""
    for c in resultat:
        mot_propre = mot_propre + c
    return mot_propre
 
 
def saisir_mot():
    mot = input("Entre un mot de 5 lettres : ").upper()
    while len(mot) != 5:
        print("Le mot doit contenir exactement 5 lettres.")
        mot = input("Entre un mot de 5 lettres : ").upper()
    return retirer_accents(mot)
 
 
def evaluer(secret, essai):
    indice = []
    for i in range(len(secret)):
        lettre = essai[i]
        if lettre == secret[i]:
            indice.append(lettre)
        elif lettre in secret:
            indice.append("!")
        else:
            indice.append("x")
 
    resultat = ""
    for caractere in indice:
        resultat = resultat + caractere
    return resultat
 
 
def jouer_partie():
    secret = retirer_accents(random.choice(MOTS))
    historique = []
    gagne = False
 
    print("=== WORDLE ===")
    print("Devine le mot de 5 lettres (" + str(MAX_TENTATIVES) + " tentatives)")
    print()
 
    for tentative in range(1, MAX_TENTATIVES + 1):
        print("Tentative " + str(tentative) + "/" + str(MAX_TENTATIVES))
        essai = saisir_mot()
        indice = evaluer(secret, essai)
        historique.append([essai, indice])
 
        for entree in historique:
            print("  " + entree[0] + " → " + entree[1])
        print()
 
        if essai == secret:
            print("Bravo ! Trouvé en", tentative, "tentatives !")
            gagne = True
            break
 
    if not gagne:
        print("Perdu ! Le mot était :", secret)
 
 
def wordle():
    continuer = True
    while continuer:
        jouer_partie()
        print()
        reponse = input("Rejouer ? (o/n) : ").upper()
        continuer = (reponse == "O")
    print("Merci d'avoir joué !")
 
 
wordle()
```
