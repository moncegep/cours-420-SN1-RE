{/* ## Projet 3 — Analyse d'un niveau Mario

### Contexte

Dans le **projet 1** du cours (constructeur de niveaux Mario), tu as produit un fichier `niveau.txt`

```python
[#][#][#][#][#][#][#][#][#][#][#][#]"""
```

```
[ ][ ][^][ ][#][ ][ ][ ][>][ ][ ][ ]      ← ligne du haut
```

### Exercice 3.3 — Compter chaque type de bloc

Écris une fonction `compter(grille)` qui retourne un **dictionnaire** avec le nombre d'occurrences de chaque type de bloc.

```python
compteurs = compter(grille)

# {'[ ]': 10, '[^]': 2, '[#]': 22, '[>]': 1, '[<]': 1}
```

<details>
<summary>🔑 Voir la solution</summary>

```python "def" "for" "in" "get"
def compter(grille):
    compteurs = {}
    for ligne in grille:
        for bloc in ligne:
            compteurs[bloc] = compteurs.get(bloc, 0) + 1
    return compteurs
```

<Aside type='tip' title='Le patron get(clé, 0) + 1'>
`compteurs.get(bloc, 0)` retourne `0` si la clé n'existe pas encore, ce qui permet d'incrémenter sans gérer le cas initial. Le dictionnaire se construit au fur et à mesure.
</Aside>

```python "def" "format" "len"
    print("=== Analyse du niveau Mario ===")
```

<summary>💡 Indice</summary>

1. Convertis la grille en tableau NumPy 2D de chaînes.
2. Récupère la dernière ligne (le sol) avec `tableau[-1]`.

```python "def" "np.array" "np.where" "list"
import numpy as np

def colonnes_dangereuses(grille):
    tableau = np.array(grille)
    sol = tableau[-1]
    indices = np.where(sol == "[ ]")[0]
    return list(indices)
```

<Aside type='note' title='np.where sur un masque booléen'>
`sol == "[ ]"` produit un tableau booléen : `True` là où le bloc est un trou. `np.where(condition)` retourne les **indices** où la condition est vraie. Le `[0]` extrait le premier élément du tuple retourné (pour un tableau 1D).

`list(indices)` convertit le résultat NumPy en liste Python standard pour l'affichage.

Dans ton projet 1, tu as calculé un score basé sur des facteurs comme le nombre de trous, la hauteur du niveau, etc. Avec les outils du chapitre, tu peux maintenant calculer ce score **à partir d'un niveau déjà construit**.

Écris une fonction `score(grille)` qui combine **5 facteurs** :

\text{score} = 2 \times \text{trous} + 3 \times \text{trampolines} + 2 \times \text{accelerateurs} + 5 \times \text{lignes} + 1 \times \text{largeur}

| Facteur | Valeur | Poids | Contribution |

| Trampolines `[^]` | 2 | × 3 | 6 |

<summary>🔑 Voir la solution</summary>

```python "def" "return" "len"
def score(grille):
    compteurs = compter(grille)
    trous = compteurs.get("[ ]", 0)
    trampolines = compteurs.get("[^]", 0)
    accelerateurs = compteurs.get("[>]", 0)
    lignes = len(grille)
    largeur = len(grille[0])

    return 2 * trous + 3 * trampolines + 2 * accelerateurs + 5 * lignes + 1 * largeur
```

### Exercice 3.8 — Visualisation du niveau

Pour vérifier visuellement que ton chargement fonctionne, écris une fonction `afficher(grille)` qui affiche le niveau **ligne par ligne** avec un indicateur de hauteur.

##### Résultat attendu
```
Ligne 3 (haut) : [ ][ ][^][ ][#][ ][ ][ ][>][ ][ ][ ]
Ligne 2        : [#][#][#][#][#][#][<][#][#][#][^][#]
Ligne 1 (sol)  : [#][#][#][#][#][#][#][#][#][#][#][#]
```

<details>
<summary>🔑 Voir la solution</summary>

```python "def" "for" "range" "len" ".join" "format"
def afficher(grille):
    hauteur = len(grille)
    for i in range(hauteur):
        numero = hauteur - i

        if i == 0:
            etiquette = format("Ligne " + str(numero) + " (haut)", "<15")
        elif i == hauteur - 1:
            etiquette = format("Ligne " + str(numero) + " (sol)", "<15")
        else:
            etiquette = format("Ligne " + str(numero), "<15")

        contenu = "".join(grille[i])
        print(etiquette, ":", contenu)
```

<Aside type='tip' title='Numérotation inversée'>
Dans le projet 1, la **ligne 1** est celle du **sol** (construite en premier). Mais dans le fichier, le sol est **à la fin**. On calcule donc `numero = hauteur - i` pour afficher la bonne numérotation.

`"".join(grille[i])` reconstruit la ligne originale en collant tous les blocs ensemble.
</Aside>
