## Mais c'est quoi, programmer ?

### Définition d'un programme

Un **programme**, c'est simplement une séquence d'instructions qu'on donne à un ordinateur pour accomplir une tâche spécifique. 

Pensez-y comme une recette de cuisine :
- 📝 Une recette = une série d'étapes précises
- 👨‍🍳 Le cuisinier = l'ordinateur
- 🍰 Le résultat = votre programme en action !

La différence ? L'ordinateur suit vos instructions **exactement** comme vous les écrivez (il ne devine rien !).

<Aside type="note" title="Exemple scientifique">
Imaginez que vous voulez calculer la trajectoire d'un projectile. Plutôt que de faire les calculs à la main pour chaque angle et vitesse initiale, vous pouvez écrire un programme qui fait tous ces calculs en quelques secondes !
</Aside>

### L'ordinateur : votre environnement dynamique

Un ordinateur, c'est bien plus qu'une grosse calculatrice ! C'est un environnement dynamique qui peut :
- 💾 **Stocker** des données (mémoire)
- 🧮 **Traiter** l'information (processeur)
- 🖥️ **Afficher** des résultats (écran)
- ⌨️ **Recevoir** des instructions (clavier, souris, etc.)

## Anatomie d'un programme Python

Voici les éléments de base de tout programme Python :

```python
# Ceci est un commentaire - Python l'ignore
# Les commentaires servent à expliquer le code

# 1. Instructions (ce que Python doit faire)
print("Bonjour le monde!")

# 2. Variables (pour stocker des informations)
nom = "Alice"

# 3. Opérations (calculs, manipulations)
temperature_celsius = 25
temperature_fahrenheit = (temperature_celsius * 9/5) + 32

# 4. Affichage des résultats
print(f"{temperature_celsius}°C = {temperature_fahrenheit}°F")
```

<Aside type="tip" title="Les commentaires sont vos amis !">
Prenez l'habitude d'ajouter des commentaires à votre code. Dans 2 semaines, vous ne vous souviendrez plus du raisonnement ou de l'intention qui a mené au code. Les commentaires vous sauveront !
</Aside>

## Votre outil : IDLE

**IDLE** (Integrated Development and Learning Environment) est l'environnement de développement qui vient avec Python. Il comprend deux modes :

### 1. Le Shell interactif (mode immédiat)

Le shell vous permet de tester des commandes instantanément :

```python
>>> print("Coucou!")
Coucou!

>>> 5 + 3
8

>>> 10 / 2
5.0

>>> 7 > 3
True
```

<Aside type="note">
Le symbole `>>>` indique que Python attend votre commande. Vous tapez, appuyez sur *Entrée*, et il évalue immédiatement votre entrée (instruction) et affiche le résultat.
</Aside>

### 2. L'éditeur (création de scripts)

L'éditeur vous permet d'écrire des programmes complets que vous pouvez sauvegarder et exécuter plus tard.
Pour créer un programme complet :
1. **File → New File** (ou Ctrl+N)
2. Écrivez votre code
3. **File → Save** (donnez un nom avec `.py`)
4. **Run → Run Module** (ou F5)

## Variables : stocker l'information

Une **variable**, c'est comme une boîte étiquetée où on range une valeur.

### Créer et utiliser des variables

```python
# Créer une variable
age = 19
nom = "Marie"
taille_metres = 1.65
est_etudiant = True

# Utiliser les variables
print(nom)                    # Affiche: Marie
print("J'ai", age, "ans")     # Affiche: J'ai 19 ans

# Faire des calculs avec des variables
taille_cm = taille_metres * 100
print("Taille:", taille_cm, "cm")  # Affiche: Taille: 165.0 cm
```

<Aside type="caution" title="Règles pour nommer les variables">
✅ Peuvent contenir lettres, chiffres, underscore (_)  
✅ Doivent commencer par une lettre  
✅ Sensibles à la casse (`age` ≠ `Age`)  
❌ Pas d'espaces  
❌ Pas de caractères spéciaux (@, #, %, etc.)  
❌ Pas de mots réservés Python (`print`, `if`, `for`, etc.)

**Bonnes pratiques :**
- Utilisez des noms descriptifs : `temperature` plutôt que `t`
- Utilisez snake_case : `vitesse_initiale` plutôt que `VitesseInitiale`
</Aside>

### Exemple : conversion d'unités

```python
# Conversion °C vers °F
celsius = 25
fahrenheit = (celsius * 9/5) + 32
print(f"{celsius}°C = {fahrenheit}°F")

# Conversion km/h vers m/s
vitesse_kmh = 90
vitesse_ms = vitesse_kmh / 3.6
print(f"{vitesse_kmh} km/h = {vitesse_ms:.2f} m/s")
```

## Interagir avec l'utilisateur : `input()`

La fonction `input()` permet de demander des informations à l'utilisateur.

### Syntaxe de base

```python
nom = input("Quel est votre nom? ")
print("Bonjour", nom, "!")
```

**Exécution :**
```
Quel est votre nom? Alice
Bonjour Alice !
```

<Aside type="caution" title="Attention au type !">
`input()` retourne **toujours** une chaîne de caractères (string). Pour des nombres, il faut convertir !
On verra ça plus en détail la semaine prochaine.

```python
# ❌ Problème
age = input("Votre âge? ")
dans_10_ans = age + 10  # ERREUR !

# ✅ Solution
age = int(input("Votre âge? "))
dans_10_ans = age + 10  # Ça marche !
```
</Aside>
