Dans ce projet, vous allez écrire un programme Python qui **dessine Mario** dans la console.
Le programme évoluera d'une version statique vers une version paramétrable et expérimentale.

Vous utiliserez uniquement :
- des **boucles** (`for`, `while`)
- des **conditions** (`if`, `elif`, `else`)
- des **fonctions** (`def`)
- les modules `math`, `time` et `random`

**Durée** : 3 semaines.

---

## Objectif

Écrire un programme **interactif** qui permet à l'utilisateur de construire
un niveau Mario bloc par bloc, en choisissant dans un menu.

Le niveau construit est sauvegardé dans un fichier texte puis testé
avec `mario_runner.py` pour vérifier si Mario peut le traverser.

```bash
python gabarit.py
python mario_runner.py niveau.txt
python mario_runner.py niveau.txt --anime
```

---

## Comment fonctionne le programme

L'utilisateur voit un menu et fait des choix jusqu'à ce que le niveau soit terminé :

```
──────────────────────────────────────────────────
→ [#][#][^]  (ligne 1)
  [?] placés : 0 / 1 minimum  ⚠ il en manque 1
──────────────────────────────────────────────────

  A) [#] Bloc       B) [ ] Vide       C) [^] Trampoline
  D) [>] Accélérer  E) [<] Décélérer  F) [?] Aléatoire
  NL) Nouvelle ligne                   FIN) Terminer

  Votre choix : F
  Combien (1 à 3) : 2
```

### Les blocs

| Option | Bloc | Effet sur Mario |
|---|---|---|
| A | `[#]` | Bloc normal — Mario marche dessus |
| B | `[ ]` | Vide — Mario tombe ! |
| C | `[^]` | Trampoline — Mario saute de +2 blocs de hauteur |
| D | `[>]` | Accélérateur — Mario avance de 2 colonnes |
| E | `[<]` | Décélérateur — Mario revient à vitesse normale |
| F | `[?]` | Aléatoire — sera remplacé par A, B, C, D ou E au test |

### Les commandes

| Commande | Effet |
|---|---|
| `NL` | Termine la ligne courante et commence une nouvelle ligne au-dessus |
| `FIN` | Termine le niveau, sauvegarde dans `niveau.txt` |

### Règle des blocs aléatoires `[?]`

Chaque ligne doit contenir un **nombre minimum** de blocs `[?]`.
Ce minimum **augmente d'au moins 1** après chaque ligne.

- Ligne 1 : au moins 1 bloc `[?]`
- Ligne 2 : au moins 2 blocs `[?]`
- Ligne 3 : au moins 3 blocs `[?]`
- etc.

Le programme doit **refuser** `NL` et `FIN` si le minimum n'est pas atteint.

## Les 4 paliers

### Palier 1 — Menu de base (minimum attendu)

**Ce que vous devez faire** :
La boucle `while` principale avec le menu, les choix A et B uniquement,
les commandes NL et FIN, et la fonction `afficher_etat`.

**Critères** :

| # | Critère | Comment vérifier |
|---|---|---|
| 1 | Le programme tourne sans erreur | Aucun crash |
| 2 | Boucle `while` jusqu'à FIN | Le menu réapparaît après chaque choix |
| 3 | `input()` pour lire le choix | Le programme attend une saisie |
| 4 | A ajoute `[#]` à la ligne courante | Visible dans l'affichage |
| 5 | B ajoute `[ ]` à la ligne courante | Visible dans l'affichage |
| 6 | NL commence une nouvelle ligne | L'ancienne ligne passe au-dessus |
| 7 | FIN sauvegarde dans `niveau.txt` | Le fichier existe après |
| 8 | `afficher_etat()` est une **fonction** | `def afficher_etat(...):` dans le code |
| 9 | L'état est affiché après chaque choix | Niveau + ligne courante visibles |

**Concepts clés** :

```python
# Construire la ligne par concaténation
ligne_courante = ligne_courante + "[#]"

# Empiler les lignes (la nouvelle va AU-DESSUS)
if niveau != "":
    niveau = ligne_courante + "\n" + niveau
else:
    niveau = ligne_courante

# Sauvegarder dans un fichier
fichier = open("niveau.txt", "w", encoding="utf-8")
fichier.write(niveau)
fichier.close()
```


### Palier 2 — Tous les blocs + quantité

**Ce que vous devez faire** :
Ajouter les blocs C, D, E et demander combien de blocs (1 à 3)
après chaque choix A-E.

**Critères** (en plus du Palier 1) :

| # | Critère | Comment vérifier |
|---|---|---|
| 10 | Les options C, D, E fonctionnent | Les blocs `[^]`, `[>]`, `[<]` apparaissent |
| 11 | Le programme demande **combien** (1 à 3) | Deuxième `input()` après le choix |
| 12 | La quantité est **validée** | Refus si < 1 ou > 3 |
| 13 | Les blocs sont ajoutés en boucle `for` | `for i in range(nb):` |

**Code attendu** :

```python
nb_txt = input("  Combien (1 à 3) : ")
# Valider que nb_txt est "1", "2" ou "3"

if choix == "A":
    bloc = "[#]"
elif choix == "B":
    bloc = "[ ]"
elif choix == "C":
    bloc = "[^]"
# ... etc.

for i in range(nb):
    ligne_courante = ligne_courante + bloc
```


### Palier 3 — Blocs aléatoires et minimum

**Ce que vous devez faire** :
Ajouter l'option F (`[?]`), compter les blocs aléatoires placés,
et empêcher NL/FIN si le minimum n'est pas atteint.
La fonction `calculer_min_aleatoires` détermine le minimum.

**Critères** (en plus du Palier 2) :

| # | Critère | Comment vérifier |
|---|---|---|
| 14 | L'option F ajoute `[?]` | Visible dans l'affichage |
| 15 | Le compteur `[?]` est affiché | « placés : 2 / 3 minimum » |
| 16 | NL et FIN sont **refusés** si pas assez de `[?]` | Message d'erreur |
| 17 | `calculer_min_aleatoires()` est une **fonction** | `def calculer_min_aleatoires(...):` |
| 18 | Le minimum augmente d'au moins 1 par ligne | Visible dans l'affichage |

**La fonction** :

```python
def calculer_min_aleatoires(num_ligne, nb_blocs_ligne):
    """Retourne le minimum de [?] requis pour la prochaine ligne."""
    # Version simple :
    return num_ligne
    # Version avancée (plus de blocs → plus de [?]) :
    # return num_ligne + nb_blocs_ligne // 5
```

Le paramètre `nb_blocs_ligne` est le nombre de blocs **non-[?]** sur la
ligne qui vient d'être terminée. Cela permet de forcer plus de hasard
si l'utilisateur pose beaucoup de blocs « planifiés ».


### Palier 4 — Validation et analyse

**Ce que vous devez faire** :

**Critères** (en plus du Palier 3) :

| # | Critère | Comment vérifier |

## Variables du gabarit

Le gabarit fournit les variables suivantes, prêtes à utiliser :

| Variable | Type | Rôle |
|---|---|---|
| `niveau` | string | Les lignes complétées (séparées par `\n`) |
| `ligne_courante` | string | La ligne en cours de construction |
| `num_ligne` | int | Numéro de la ligne actuelle (1, 2, 3...) |

| `fini` | bool | `True` quand l'utilisateur choisit FIN |

> **Pas de listes !** Le niveau est construit entièrement avec des
> variables simples (strings, int, bool) et de la concaténation.
